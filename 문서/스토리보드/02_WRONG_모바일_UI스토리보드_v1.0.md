## A. 서비스 기획 요약
- **목적:** 사진·글로 오답을 기록하고 끝내지 않고 아이 재풀이 → 정답 비교 → 부모의 관찰 → 다음 확인 → 복습 이력으로 연결한다.
- **대상:** 보호자(사진/OCR 검토/저장/관찰/확인 희망일/이력/개인정보), 아이(허용된 재풀이 목록/답·설명/결과).
- **핵심 가치:** 재풀이를 중심에 두고 **과거 관찰**, **아직 하지 않은 미래 질문**, **정답 일치**, **학습 수준 추정**을 혼동하지 않는다. 보기 모드 전환은 계정 인증이 아니다.
- **개발본에 확인된 코드:** `index.html`의 홈/등록/목록/상세/개념/설정, 사진만 저장, 선택형 OCR·수동 수정, 재풀이·부모 관찰·기록 집계/백업 진단. 실제 인증/기기보존/배포와 구별.

**화면 공통 상세:** 390px 기준 실제 앱과 유사한 헤더/메뉴/카드/입력란/상태/버튼이 표시된다. 320px에서는 `min-width:0`, 줄바꿈, 한 열 카드, 가로 스크롤 금지, 버튼 약 46px 이상의 터치 목표를 적용했다. **실제 브라우저 320px 렌더 측정·실기기 접근성 테스트는 이 문서 작성 단계 미확인**(후속 검증 필요).

**부모/아이 권한:** 부모 모드와 아이 모드는 UI 보기 상태일 뿐 인증이 아니다. 부모의 개인 메모·OCR 미확정 초안은 아이 화면 DOM 비노출이 목표다. 실제 가족별 인증/403·실서버 분리·삭제는 검증되지 않았다. 데모는 실제 가정 자료를 저장·전송하지 않는다.

## E. 개선 제안·우선순위
1. **P0 데이터 안전:** 가족별 서버 인증/소유권 검증 전 '부모 전용'을 보안 완료로 표시하지 말고, 안전한 복원/실삭제 버튼은 사용 불가 처리. 실제 서비스를 수정하는 제안이지 본 HTML에 보안 기능을 구현했다는 뜻이 아님.
2. **P0 저장 신뢰성:** 사진 원본·문제 텍스트·OCR 초안과 확정 텍스트를 구분하고, 비동기 OCR 및 두 탭 편집 시 원본 바이트 보존을 제품별 실증.
3. **P1 화면 축소:** 홈 상단에는 등록·오늘 재풀이, 목록은 '사진만 저장/재풀이 필요/확인 희망' 상태 필터만 먼저 제공.
4. **P1 부모 이력:** 부모가 직접 기록한 관찰과 미래 질문의 미확인 상태를 별도 표기하고 자동 진단/정답률로 오인하지 않도록 함.
5. **P2 사용성:** 실물 320/390px, 화면 200% 확대·키보드/스크린리더, 긴 한국어 제목/수학 수식 overflow를 후속 검증.
