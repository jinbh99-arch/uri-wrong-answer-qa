4. 오래된 수정 차단 — 독립 시험 DB

실제 오답노트 본체의 저장소에는 접근하지 않고, 동일한 시험용 IndexedDB에 별도 연결 2개를 열어 기록을 비교합니다. 연결 B가 시험 기록을 먼저 변경한 뒤, 연결 A의 오래된 내용이 같은 읽기·쓰기 트랜잭션 안에서 차단되는지 확인합니다.

미실시

이 검사는 본체 보호 로직의 원리를 별도로 재현한 것입니다. 실제 앱의 두 탭 UI 경쟁 상태까지 검증한 것으로 표시하지 않습니다.

5. 시험 저장소 정리

시험 전용 IndexedDB 하나만 삭제합니다. 실제 오답 기록은 삭제하지 않습니다. 완료 후 이전 시험 결과는 초기화됩니다.

미실시

검증 결과 로그

①·②는 실제 IndexedDB 저장·재읽기, ③은 동일 출처 두 탭의 데이터 조회, ④는 별도 시험 저장소 내 보호 알고리즘 재현을 확인합니다. 운영 앱의 복원 중단·동시 수정 충돌 방지, 실제 카메라·OCR, 장기 보존까지 검증한 결과는 아닙니다. 시험용 데이터만 사용하세요.
