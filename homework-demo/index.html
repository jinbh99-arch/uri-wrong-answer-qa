실제 개발본과 차이

이 페이지는 내부개발 v0.77의 **화면 구성과 주요 사용자 흐름을 기반으로 제작한 독립 시연용 화면**입니다. 기존 앱의 Cloudflare 인증·D1·암호화 서버·실시간 다기기 통신은 들어 있지 않습니다.

직접 가능한 체험: 보호자/아이 화면 전환, 숙제 등록 시 최종 확인, 진도 기록, 준비물 체크, 문자 후보 추출, 알림 표시.

불가능한 작업: 실제 로그인·서버 저장·실시간 기기간 동기화·푸시 발송·OCR 정확도 검증·실제 사진 업로드.

내부개발 목표 완료율은 10/15(67%)입니다. 운영 서비스가 아니므로 가상 데이터 외의 개인정보를 입력하지 마세요.
