가족별 기록 교환 실험실

실제 자녀 정보 사용 금지

이 도구는 개발용 가상 기록만 연결합니다. 이 페이지는 로컬 127.0.0.1:4173에서만 실행할 수 있으며, GitHub Pages에서는 접속·업로드·다운로드 기능이 비활성화됩니다. 실제 가족 가입이나 운영 클라우드 동기화가 아닙니다.

1. 임시 로컬 서버 연결

시험용 Node 서버 실행 시 표시되는 임시 포트를 입력하세요. 서버는 외부 인터넷에서 접속할 수 없으며, 기록은 시험용 파일에만 암호화 저장됩니다.

토큰과 비밀번호는 브라우저 메모리에서만 사용합니다. 새로고침하면 자동으로 로그아웃됩니다.

가상 비밀번호 변경 및 모든 기기 로그아웃

가상 가족 비밀번호를 변경하면 기존 모든 기기의 로그인은 즉시 폐기되며 다시 로그인해야 합니다. 서버 오답·사진은 유지됩니다. 운영 계정 복구 기능은 아닙니다.

2. 합성 데이터 수동 교환

오답노트 설정 → 기록·사진 백업에서 생성한 가상 데이터 JSON만 선택하세요. 서버에서 가져온 파일은 오답노트의 “백업 복원”에서 직접 불러와야 합니다. **자동 동기화는 제공하지 않습니다.**

가상 가족 서버 미연결 · 개정번호 미확인

3. 서로 다른 기기 변경 수동 병합

반드시 먼저 기준 버전 백업을 이 화면에서 내려받고, 그 기준으로 작업한 다른 기기의 합성 JSON 파일을 선택하세요. 서버는 저장해 둔 기준 버전과 실제로 대조합니다. 동일 오답 동시 수정·삭제가 발견되면 자동 합치지 않습니다.

기준본과 변경본을 선택하면 충돌 여부를 확인할 수 있습니다.

4. 시험용 가족 기록과 로그인 폐기

가상 가족의 서버 기록·버전 이력·로그인 세션을 삭제합니다. 이 동작은 취소할 수 없습니다. 다운로드해 둔 외부 백업이나 파일 시스템의 이전 흔적까지 안전하게 지운다는 보장은 없습니다.

연결 대기 중입니다.

이 화면은 교육연구 또는 개인정보 보안 인증을 통과한 서비스가 아닙니다. 최신 개정번호가 바뀌면 자동 덮어쓰기를 차단합니다. 이 경우 원본 JSON을 보관하고 충돌 원인을 확인해야 합니다.
