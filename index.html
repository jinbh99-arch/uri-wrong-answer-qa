2. 문제 내용 확인

문제 내용은 직접 입력하거나 선택형 OCR 시범 기능을 사용할 수 있습니다. OCR은 별도 동의 시에만 외부 라이브러리를 다운로드하며, 추출된 글자를 확인하고 적용해야 합니다. 수식·도형은 잘못 인식될 수 있습니다.
🔤 사진 글자 인식 시범 (선택)

사진을 선택하고 문항 영역을 지정한 다음 실행하세요. 동의 후 OCR 실행 코드·한국어 모델 등을 인터넷에서 내려받아 브라우저에서 글자를 분석하도록 설계했습니다. 사진을 외부 OCR 서버에 올리는 앱 코드는 없지만 제3자 실행 코드의 실제 통신·보안은 배포 전 별도 검증이 필요합니다. 직접 입력은 언제든 가능합니다.

보정은 글자 인식에 전달하는 임시 이미지만 바꿉니다. 저장되는 원본 문제 사진은 바뀌지 않으며, 흐린 연필 글씨는 오히려 덜 보일 수 있어 원본 색상과 비교해 선택하세요.

사진을 선택하면 OCR 버튼이 활성화됩니다. 인터넷이 없는 환경에서는 직접 입력하세요.

🔍 사진과 OCR 결과를 비교할 때 확인할 5가지

① 숫자와 자릿수 ② 더하기·빼기·곱하기·나누기 기호 ③ 분자·분모·분수선 ④ 괄호·단위·부등호 ⑤ 도형·표·그림에 빠진 조건. OCR은 정답 채점이나 오답 원인 판정이 아닙니다.

OCR 결과를 수정한 뒤 문제 내용에 추가 또는 기존 문장 교체를 선택하세요. 교체는 별도로 확인받으며, 사진이나 기존 기록을 자동으로 덮어쓰지 않습니다.

사진 속 분수·도형·수식은 자동 인식에 오류가 있을 수 있습니다. 이 표시만으로 정답이나 개념 이해가 검증되는 것은 아닙니다.

입력하지 않으면 오답의 실제 원인을 알 수 없습니다. 학부모 관찰 및 복습 질문으로 확인해 주세요.
