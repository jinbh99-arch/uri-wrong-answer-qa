## 채택한 데이터/화면 계약

- **새 필드 아님:** 기존 `subject`를 레코드별 선택값 `math/korean/english/science/social`로 허용하고, 기존 `gradeAtEntry`를 개별 오답의 **학부모 수동 입력 학년 1~6**으로 사용. 기존 수학 오답은 과거 `subject='math'`와 원래 `gradeAtEntry`를 변경하지 않음. 새 오답의 기본 학년은 기존 프로필 학년; 프로필의 `subject='math'`는 이전 저장·복원 호환을 위해 유지되지만 *개별 오답의 과목이 아님*.
- **고유 ID·사진 키:** 기존 `id='m'+uuid` 및 `photos[id]` 그대로 유지. 원 PRD의 `error_id` 별칭/정식 UUID 계약, 숙제/레벨과 자동 연결은 이번에 생성하지 않음. 리키·일괄 마이그레이션 없음.
- **지원하는 기능:** 수학은 기존 개념 후보·수학 시범·복습 계획 및 일반 재풀이 그대로. 국어/영어/과학/사회는 **오답 등록·수정·사진·원인 후보 0/1/N·일반 재풀이·학부모 수동 관찰(`checkHistory`)·보고서·필터·백업·복원**만. 수학 전용 개념/선수 그래프·교육과정 코드·시범 풀이를 강제 노출하지 않음. `conceptId=''`인 **미분류**를 명시하며 실제 교육적 후보 매핑 없음.
- **비수학 복습 제약:** 기존 `studyPlan`/수학 개념 `followupHistory` 전용 기능은 **미지원**(그럴듯한 가짜 일반 플랜 생성 금지). 대신 학부모가 오답 상세에서 수동으로 관찰할 수 있음. 과목 분류를 수정하더라도 기존 학습이력·관련 개념을 지워야 한다면 편집 **fail-closed**. 저장 시 원본 구조를 덮지 않음.
- **기존 데이터 경계:** 인덱스 DB 전체 읽기에서 `subject==='math'` UI 필터를 제거하되, 지원하지 않는 과목/비수학 레코드에 수학 전용 이력이 붙은 상태를 일부만 숨기지 않고 오류로 중단. 기존 `v221` 저장소 전체 안전 점검, `v214` 일관성 백업, `v18/v215` 사전복원 검증, 레코드별 사진과 ID·다른 탭 CAS 보호 유지. 알 수 없는 과목·학년 범위 밖·비수학 수학개념/계획은 복원 거절. 사용자 편집을 수반하지 않는 저장 기록의 자동 변환 없음.
