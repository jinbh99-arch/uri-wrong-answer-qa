# 우리아이 오답노트 — 가상 오답 1건으로 살펴보는 학부모 화면 안내 (v1.0)

> **ZIP 없이 보기:** [수정 후 가상 화면 10장을 GitHub에서 개별로 보기](./qa79-fixed-320px/README.md) (정상 `fixed/` 화면만)

> **범위:** 비운영 로컬 Chromium 320px 가상 시연입니다. 실제 서비스 접속·가족별 인증·실폰 작동·실제 OCR 검증이 아닙니다. `safeToRestore:false` 유지. 화면의 **부모/아이 모드 버튼은 가족 인증 수단이 아닙니다.**

## 실제 화면 열람 방법

- **수정 후 정상 흐름 10장만 사용:** [QA79 GitHub Actions 화면 증거 ZIP (artifact #14121874656)](https://github.com/jinbh99-arch/uri-wrong-answer-qa/actions/runs/43617826347/artifacts/14121874656)
- GitHub 로그인이 필요한 경우 로그인 후 ZIP을 내려받아 **`fixed/` 폴더**의 `01`~`10` PNG를 순서대로 엽니다. 각 이미지는 **너비 320px의 실제 Chromium 전체 페이지 캡처**이며, 길이는 단계마다 다릅니다.
- 같은 ZIP 안의 **`baseline/` 10장에는 수정 전 부모 관찰 결과가 아이 화면의 숨김 DOM에 남은 결함**이 있으므로 **정상 제품 화면으로 소개하지 않습니다**.
- [검증 실행 기록](https://github.com/jinbh99-arch/uri-wrong-answer-qa/actions/runs/43617826347) · [제품 반영 PR #67](https://github.com/jinbh99-arch/uri-wrong-answer-qa/pull/67)

## 학부모가 살펴볼 순서 — 같은 가상 오답 1건

| 순서 | 수정 후 캡처(파일명) | 화면에서 한 일과 확인할 점 |
|---|---|---|
| 1. 화면 진입 | `fixed/01-parent-entry.png` | 첫 화면의 **가상자료 전용 로컬 QA** 안내를 확인합니다. 메뉴에서 **오답 등록**을 선택할 수 있습니다. |
| 2. 오답 등록 | `fixed/02-parent-registration.png` | **과학**을 선택하고 가상 문제 문장, 아이의 최초 답, 학부모 메모와 **1픽셀 가상 PNG**를 입력합니다. 실제 학생 사진은 사용하지 않았습니다. |
| 3. 사진·원본 저장 | `fixed/03-parent-record-saved.png` | **저장** 뒤 같은 오답의 상세 화면과 사진을 확인합니다. 이 시점의 오답 ID·사진 바이트가 이후 단계에서도 보존되는지 검증했습니다. |
| 4. 아이의 설명 | `fixed/04-child-explains.png` | **아이 학습 화면**으로 바꾸고, 아이가 같은 사진 문제를 보며 **다시 푼 답과 자신의 설명**을 직접 입력합니다. 답이나 원인을 자동 생성·판정하지 않습니다. |
| 5. 아이 재풀이 저장 | `fixed/05-child-retry-saved.png` | **다시 푼 기록 저장**으로 첫 설명 이력을 남깁니다. 새 오답을 만든 것이 아니라 **같은 오답 ID**에 기록이 추가됩니다. |
| 6. 부모 관찰 | `fixed/06-parent-observation.png` | **부모 화면**으로 돌아와 아이의 설명을 읽고 **학부모 관찰**에서 ‘도움이 필요했다고 관찰’을 선택·저장합니다. 이는 부모가 관찰한 사실이지 AI의 오답 원인 확정이 아닙니다. |
| 7. 재확인 질문·이력 | `fixed/07-parent-followup-history.png` | **다음 확인 희망일**과 학부모가 직접 만든 질문을 **확인 전 상태의 수동 메모**로 저장합니다. 자동 알림이나 학습 완료 판정은 아닙니다. |
| 8. 아이 화면 복귀 | `fixed/08-child-after-parent.png` | 아이 모드로 전환합니다. 아이의 사진·설명은 유지되지만 **부모 메모·재확인 질문·부모 관찰 판정과 전용 입력 폼은 숨김 DOM에서도 제거**되어야 합니다. |
| 9. 같은 오답 재진입 | `fixed/09-child-reentry.png` | 아이 화면에서 홈→오답 목록→**같은 문제**를 다시 열어도 부모 전용 정보가 DOM에 재생성되지 않는지 확인했습니다. |
| 10. 부모 복귀 | `fixed/10-parent-returns.png` | 다시 **부모 화면**으로 전환하면 기존 부모 메모·관찰 결과·재확인 질문이 보존되어 확인 가능합니다. **원본 가상 사진 바이트·오답 ID 및 저장 이력**은 변경되지 않았습니다. |

## 검증된 내용과 아직 검증되지 않은 내용

**로컬 검증 완료:** 동일한 가상 오답 1건이 등록→아이 설명→부모 관찰→재확인→아이·부모 왕복을 실제 Chromium 320px에서 완주했습니다. QA79 수정 전후 각각 11/11 PASS, 수정 후 장면 10장 확보. 부모 전용 정보의 아이 숨김 DOM 잔존은 수정 전 재현되고 수정 후 검사에서 사라졌습니다. 가상 사진 원본 바이트 불변, 오답 ID 동일, 의도한 이력 추가, 외부 요청·브라우저 오류·320px 가로넘침 0을 확인했습니다.

**미검증·출시 차단:** 실아동 정보, 실기기, 실제 OCR 모델, 실제 가족 인증/권한 분리, 현재 Netlify 호스팅·인증 상태, 운영 DB·사진 스토리지 분리, 06의 독립 동적 재실행. 위 설명은 **로컬 시연 안내**이지 **실제 접속 가능한 배포 안내나 출시 승인**이 아닙니다. 보호 기준본 A, main, 공개/운영 사이트, 광고, 운영·실가족 데이터는 변경하지 않았습니다.

**출처 구분:** 화면 증거의 최상단 시연 출처 SHA는 QA79 시작 시점의 `d8c44b165a2cb3c9b0525c00f0d0843437eff639`입니다. 이 시작점에 수정 패치를 적용한 `fixed/` 화면이므로, **제품에 병합된 실제 dev SHA `e626348a190a3d1fa90f328eb32af88307122ff8`의 외부 배포·표시 증거로 오인하면 안 됩니다.** 제품 병합의 근거는 PR #67, 기존 CI 성공과 현재 dev ref입니다.

**관리:** #82 운영카드에서 00 총괄이 배정한 **기존 화면 안내서 1건**. 재시험, 신규 제품 기능, 새로운 예약, 실제 배포는 수행하지 않았습니다.
