# QA43 · 3단계 모바일 출시 전 검증 및 실기기 검수표 v1.0

## 자동검사 실행
`tests/qa43-mobile-release.mjs`: 실제 Chromium의 320px·390px 모바일 폭, 키보드 Tab/레이블/화면 상태 알림, 만료 JWT 연결 차단·토큰 미보관, 오프라인 로컬 오답 입력·새로고침 복구, 공개/localhost 원점에서 QA 기능 숨김 확인. 기존 `tests/qa-mobile-accessibility.mjs` 및 사진·OCR 회귀검사와 합쳐 CI 실행.

**주의:** 브라우저의 모바일 화면 모의 검증이지 실제 Android/iOS 물리 카메라·브라우저/네트워크 검증이 아님.

**검수 방식:** 가능하면 자녀 자료가 없는 합성 계정으로 먼저 시험하고, 실행환경·기기 모델·운영체제·브라우저·결과·스크린샷/재현 방법·승인자를 기록한다. 실기기 없이 모든 항목 '통과' 기록 금지.

**출시 기준:** 320/390px Chromium 자동검사 PASS만으로 실기기 수락 또는 운영 승인으로 처리하지 않는다.
