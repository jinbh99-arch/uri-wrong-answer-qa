## 4. 검증의 한계·남은 게이트

- 이 시험은 **실제로 브라우저가 받은 원본 JSON을 사용자가 선택한 것과 같은 경로로 재주입한 합성 테스트**이며, 앱이 외부 드라이브에 파일을 안전하게 저장하거나 백업이 장기 보존됐다고 보증하지 않는다.
- SHA-256은 **손상 검사값이지 인증 서명이나 암호화가 아니다**. 파일과 검사값을 함께 바꾸는 공격까지 검증하지 못하며, 두 번의 비동기 스냅샷 비교는 두 시점 사이/이후의 ABA·공격성 동시 쓰기를 원자적으로 방지하지 않는다. 실제 데이터 복구·무결성의 법적 증거 인증 수단 아님.
- 손상 장부 **자동 수정·강제 삭제·재등록/잠금 해제는 미구현·BLOCK**. 사용자가 원본 파일을 충분히 보관한 이후의 수동 정리·해제 UX/atomic CAS/이중백업/실제 OCR·서버 ACK·기기 강제 종료·저장 공간 부족·Safari 실기기·가족 실계정은 모두 **미검증**.
- 제품 `dev`, main, PR80·PR82, 실가족/아동·운영 DB/계정·광고/배포/예약 등 변경0. A격리 PASS를 B/C/D 또는 `safeToRestore:true`로 승격하지 않는다. 후속 승인 전 제품 병합·실자료 사용 금지.
