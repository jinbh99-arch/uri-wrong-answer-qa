# 오답노트 법정대리인 안내·동의서 — 검토용 초안 v1.0

**미사용 초안. 실보호자 확인·동의 수집 절차 미구현.** 운영 주체·계정 확인 방법·아동 대상 연령·처리 목적·보관기간·철회 창구가 정해지고 관련 법적 검토를 마치기 전 실제 동의 요청으로 사용하지 않는다.

## 법정대리인에게 제공할 안내 (초안)

이 서비스는 자녀의 초등 수학 오답, 풀이 과정, 복습 이력, 보호자 관찰 기록을 정리하기 위한 도구입니다. 사진과 수기 답안에는 자녀 또는 제3자의 개인정보가 포함될 수 있습니다. AI가 작성한 개념 설명이나 자동 추천은 공인된 학습 진단·의학적 판단이 아닙니다. 학습 결과·성취기준 연결은 공식 자료 검증 상태에 따라 별도로 표시합니다.

- 개인정보처리자 및 문의처: **[운영 주체·연락처 미확정]**
- 아동 정보 범위: **[학년·선택 닉네임·오답/풀이·복습·선택 사진 등 최종 결정]**
- 이용 목적·법적 근거·제공자·저장 지역/기간: **[관련 검토 후 확정]**
- 동의 거부권과 기능별 불이익: **[해당 기능별 정확한 안내 필요]**
- 열람·다운로드·정정·삭제·철회와 신청 채널: **[구현 및 연락처 필요]**

## 독립된 확인·동의 항목 제안

| 구분 | 검토 전 표시 문구 | 비고 |
|---|---|---|
| 신원·대리권 | 본인이 해당 아동의 적법한 법정대리인임을 확인할 수 있도록 필요한 절차에 응합니다 | **실제 신원·관계 검증 전 자동 승인 금지** |
| 서비스 필수 개인정보 | 서비스에 필요한 최소 항목·목적·보유 기간 안내를 읽고 [필수 동의 해당 여부 검토] | 법적 근거/대체 방법 검토 |
| 사진 등록·클라우드 보관 | 사진에는 불필요한 이름·학교 정보가 포함되지 않도록 확인한 뒤 선택해 등록합니다 | **선택 기능**, 외부 저장 별도 고지 |
| 외부 OCR/AI 사진 전송 | [구체적 외부 공급자·항목·지역·목적·기간] 확인 후 사진 전송에 별도 동의합니다 | 승인 전 비활성화, 미동의 시 수동 입력 |
| 학습효과 연구 참여 | 독립 연구정보 설명·철회권·학교/기관 윤리 승인 확인 후 별도 선택합니다 | 일반 서비스 이용과 분리, 현재 모집 불가 |

## 철회·신청
보호자는 관련 법령과 서비스 정책 범위 내에서 자녀의 기록 열람·정정·삭제·동의 철회를 요청할 수 있습니다. 구체적 방법·처리기한·신원확인 및 백업 파기 방식은 **[운영 및 법적 승인 전 미확정]**. 연구 참여를 거절하거나 중단해도 일반 서비스 이용에 불이익을 주지 않도록 별도 검토합니다.

### 승인 전 확인표
- [ ] 실제 법정대리인 확인/권한 부여·철회 구현 및 침해 테스트
- [ ] 목적·항목별 근거, 사진/OCR 및 제3자 제공/국외 이전 검토
- [ ] 미성년자 고지·동의 항목과 거부권·철회/삭제 처리 법률 검토
- [ ] 실제 운영자·연락처·저장국가·위탁처·보유기간 확정
- [ ] 실제 동의 화면·증빙·부모 사용성 테스트 및 관리자 승인

**현재 상태:** 모두 미승인. 가상 QA의 `qa42-synthetic` 체크박스는 실보호자 동의가 아니다.
