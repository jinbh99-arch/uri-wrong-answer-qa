# QA43 · 1단계 운영 보안·인증 연결 준비 v1.0

**상태:** 설계·코드 사전검사 준비 완료 / 외부 서비스 선택·법정대리인 검증·법률 승인 미완료  
**원칙:** 실제 공급자/키/도메인/자녀 데이터는 본 공개 GitHub QA 저장소에 저장하지 않는다.

## 구현·구성 계약
- `data/qa43-operating-candidate.template.json`은 예시 도메인(.invalid)과 *비밀관리 시스템 경로 예시*만 포함. 운영 자격증명은 없음.
- `scripts/qa43-ops-preflight.mjs`와 `tests/qa43-ops-preflight.mjs`: 잘못된 HTTPS 출처, 운영 모드 자가 승인, 개인키·DB 비밀번호 직접 기입, RLS 해제, 공개 DB·사진 저장소, 토큰 철회 정책 부재를 실패로 처리. 반환값은 **VALID_DRAFT_NOT_DEPLOYABLE**만.
- IAM: 관리자/마이그레이션 계정과 앱 계정 분리, 앱 계정은 가족 등록/삭제·권한 부여·BYPASSRLS 불허. DB는 비공개망·TLS·최소권한·감사 로그가 필요.
- 실제 인증 공급자 선택 후: 공식 Issuer/JWKS 신뢰·key rotation/폐기·API Audience·Access Token 유형·Scope·exp·iat·nbf·로그아웃/재인증·세션 갱신·재설정 오남용 검증. *ID Token을 API Access Token으로 간주하지 않음*. 권한 철회는 서버측 보호자 관계 DB에서 즉시 반영돼야 하며, 오래된 JWT만으로 접근 불가.
- 서명 키·DB·사진 저장소 자격증명은 전용 비밀관리자에 보관·배포 시 주입·주기 교체, CI 로그·소스·브라우저·다운로드 파일에 미노출. 운영 사고 시 즉시 회수/교체·기존 세션 폐기.
- API: 승인된 HTTPS 원점만 CORS, 서버 세션 인증이 필수(CORS만으로 인가 불가), 엄격한 Content-Type·If-Match·사전 개정 검사, bounded JSON, 사진 EXIF/메타데이터 안전 검토, 패밀리별 감사 로그(토큰·사진·답안 본문 금지).
- 운영 자동화: 비공개 DB 스키마 변경은 사전 백업과 단계별 롤백 계획 후, 배포 파이프라인은 테스트/스테이징/운영 승인 분리. 실제 Key/Host 설정은 공급자·비용 승인 이후.

## 권한·최종 수락 증거
| 항목 | 시험 기준 | 현 상태 |
|---|---|---|
| 실제 공급자 선정/계약 | 해당 업체 요금/지역/계정 권한 승인 | 미확정 |
| OAuth/OIDC 실제 로그인 | 공식 발급·키 회전·복구·세션 폐기 | 미실시 |
| 법정대리인 확인 | 실제 보호자 권한 및 동의 증빙 | 미실시 |
| 운영 DB 최소권한/RLS | 실제 공급자 비공개망·침투/감사 결과 | 미실시 |
| 저장·삭제·사고대응 | 개인정보처리 방침/계약·감사 자료 | 미승인 |
| 복구 RPO/RTO | 운영 주체의 수치 결정·PITR 실측 | 미실시 |

**출시 금지:** 합성 CI PASS는 운영 승인이나 법정대리인 인증이 아니다. 이 문서는 운영에 필요한 설정 구조·검증 목록을 제공할 뿐 실제 운영 연결을 수행하지 않는다.
