# 02 WRONG 모바일 UI 스토리보드 v1.1
> **기획 시안** — 실제 앱 캡처나 배포 화면이 아님. [연속 폰 시안](./02_WRONG_모바일_UI스토리보드_v1.1.svg)

## 화면·버튼 동선
| 화면 | 역할 | 주요 내용과 입력 | 누를 버튼 → 다음 화면 |
|---|---|---|---|
| 01 사진 등록 | 부모 | 과목·날짜·사진 선택, 원본 미리보기 | OCR 초안 확인 → 02 |
| 02 OCR 검토 | 부모 | 인식 텍스트 수정, 원본 사진 별도 보존 | 수정 저장 → 03 |
| 03 오답 목록 | 아이 | 승인된 재풀이 대상, 부모 메모/OCR 초안 숨김 | 문제 보기 → 04 |
| 04 재풀이 | 아이 | 문제·답 입력·확인·다음 문제 | 확인 → 05(부모 관찰은 별도 부모 접근 필요) |
| 05 부모 관찰 | 부모 | 과거 관찰과 미래 재확인 구분, 메모 | 목록 → 03(아이 화면은 별도 모드) |

## 390/320px 반응형 설계
390px 기준 화면은 단일 열, 상단 제목/상태·중앙 입력 카드·하단 명시적 동작으로 구성. 320px에서는 카드 가로폭을 화면에 맞추고 긴 제목 줄바꿈, 버튼 최소 터치 영역, 세로 스크롤을 허용하며 수평 스크롤은 금지. 키보드 초점 순서는 제목→입력→확인→뒤로, 200% 확대/스크린리더 검증은 미완료.

## 구현과 예정의 경계
| 항목 | 상태 |
|---|---|
| 오답·사진·부모 관찰 기본 흐름 | 기존 dev 기반 개념 묘사, 화면별 실제 일치 미검증 |
| OCR 결과 수정·느린 콜백의 아이 DOM 완전 제거 | W3 별도 검증 대기 |
| 가상 두 가족 접근 차단 | W4 합성 시험/인가 경계 미완료 |
| 320px·200% 확대 및 키보드 | W9 미검증 |
| 암호화 복원·삭제·실가족 인증 | 승인 대기, **safeToRestore:false** |
| 원본 사진·오답 원장 | 무손실 보호 요구, 이 문서는 데이터를 변경하지 않음 |

**보안:** 아이 화면에 부모 메모·사진 편집 흔적·OCR 초안 노출 금지. 보기 모드 전환은 인증이 아니다. 실 OCR, 가족 데이터, 운영 DB, 공개 배포를 사용하지 않음.
