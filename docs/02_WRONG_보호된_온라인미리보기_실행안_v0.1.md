## 1. '열리는 링크'로 인정하는 조건 (우선순위)
1. 관리자가 **기존 Netlify 팀 보호를 유지**하며 비운영 사이트·기존 별칭/Preview URL·접근정책·현재 배포 SHA를 읽기 전용 확인. 주소나 보안 정책을 확인 못하면 출처 없는 새 URL을 만들어 소개하지 않음.
2. 실제 최신 코드를 시험해야 할 경우 **개인정보 없는 가상 시연 프로필만** 사용. 운영·실가족 데이터를 로드하거나 같은 출처 기존 IndexedDB를 읽으면 안 됨. 원본 제품에서 위험한 '백업 복원·전체 삭제·사진 원본 내보내기·외부 OCR 코드 로드' 등은 사용/시험하지 않음. 웹 테스트 환경의 출처와 저장소를 기존 운영/기존 비공개 주소에서 물리적으로 분리.
3. 08/00이 완전히 분리된 **새 보호된 시험 URL**, 배포할 *정확한 원본 SHA 또는 안전한 가상 데모 SHA*, 자동배포 비활성화, 비로그인 401/403, Preview/별칭 차단, 캐시/로그·원복 가능성을 **각각 증빙**.
