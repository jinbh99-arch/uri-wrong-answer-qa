# 02 WRONG — 학부모·아이 로컬 클릭형 가상 체험 안내 (비배포)

> **개발자용 로컬 시연**입니다. 외부 인터넷 미리보기·가족 인증·실사용 승인이 아닙니다. **실제 아동 이름·사진·기록을 입력하지 마세요.** 부모/아이 **보기 모드 전환은 접근 인증이 아닙니다.** `safeToRestore:false` 유지. 공개 Netlify/Pages는 이 안내의 실행 대상이 아닙니다.

## 먼저 화면으로 살펴보기 (설치 불필요)

[수정 후 고정 10장 개별 열람 갤러리](../qa79-fixed-320px/README.md) — GitHub에서 각 PNG를 ZIP 없이 직접 클릭할 수 있습니다. [단계별 부모 설명](../wrong-qa79-parent-photo-guide-v1.md). **baseline/ 결함 화면은 정상 시연에 포함하지 않습니다.** 이 10장은 기존 QA79의 기록이며 최신 dev 실배포 증거가 아닙니다.

## 실제 클릭해 보는 방법 (PC 개발환경만)

1. GitHub 저장소의 **dev** 브랜치를 별도 로컬 폴더에 체크아웃합니다. 예: `git clone --branch dev https://github.com/jinbh99-arch/uri-wrong-answer-qa.git wrong-local-demo` 후 `cd wrong-local-demo`. 실행 전에 `git rev-parse HEAD`로 SHA40을 기록합니다.
2. Python 3가 설치된 PC에서 `python3 -m http.server 8766 --bind 127.0.0.1`을 실행합니다(Windows에서는 `py -3 -m http.server 8766 --bind 127.0.0.1`). **127.0.0.1만 사용**하고 `0.0.0.0`·포트포워딩·공개 호스팅을 사용하지 않습니다.
3. 기존 개인 브라우저 프로필이 아닌 **새로운 임시 테스트 프로필**에서 `http://127.0.0.1:8766/index.html`을 엽니다. 실제 아이 데이터가 있는 브라우저 프로필은 사용하지 마세요. 개발자도구 모바일 뷰포트는 **320px**로 설정합니다. 로컬 서버는 별도 비밀번호를 제공하지 않으므로 PC 자체 접근 제한이 전제입니다.
4. 아래 동선을 **합성 문항 한 건**으로 클릭합니다. 실제 사진 대신 직접 만든 **1픽셀 가상 PNG**를 쓰거나 사진 없이 텍스트 가상 문항으로 진행합니다. OCR은 동의하거나 실행하지 않습니다. 실제 저장/버튼 이름이 화면에서 다르면 **추측하여 다른 기록을 삭제하거나 복원하지 말고 미완료로 기록**합니다.
5. 종료 후 서버를 Ctrl+C로 중단합니다. 임시 프로필은 테스트 전용인지 확인한 뒤에만 폐기합니다. **기존 브라우저의 IndexedDB·사진·오답 원장 삭제 금지**.

## 부모·아이 관점의 미완료/접근성 점검표

- **부모:** 사진 선택·등록·저장 버튼이 320px에서 가려지거나, 저장 완료/오류 피드백이 모호하면 **미완료**. 새로고침·뒤로가기 중 미저장 입력이 사라지는지 별도 확인 필요.
- **아이:** 재풀이 입력·설명·저장 버튼을 키보드 Tab/Enter로 사용할 수 있는지, 화면 확대·초점 표시·읽기 순서·오류 안내는 **이번 회차 새 실증 없음**.
- **개인정보:** 부모 메모가 아이 보기에서 숨김 DOM/접근성 트리/스크립트 캐시에 남지 않는지 기존 QA79의 가상 검증만 승계. **실제 가족 인증, 다른 기기·탭 권한 분리, 실OCR·실사진, 운영 저장소 격리 미검증**.
- **자료 보호:** 원본 사진 바이트·기존 오답 원장·백업/복원·두 탭 경합의 실사용 무손실은 이번 로컬 안내로 재검증되지 않음. `safeToRestore:false` 유지.

**판정:** 기존 fixed PNG 10장 열람 + 현재 dev 로컬 클릭 체험 *실행 절차* 제공. 실제 사용자의 클릭 성공, 실기기, 외부 인증/호스팅, 운영 배포는 **미완료**. 기존 [QA79 증거](https://github.com/jinbh99-arch/uri-wrong-answer-qa/actions/runs/43617826347)는 재실행하지 않았습니다.
