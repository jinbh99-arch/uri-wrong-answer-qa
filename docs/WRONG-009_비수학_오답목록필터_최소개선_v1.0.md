# WRONG-009 · 비수학 4과목 오답 목록의 수학 전용 필터 혼동 최소 수정 v1.0

작업일: 2026-11-10 KST · 근거: 공통 `uri-homework-manager#52` 최신 §18 · 담당: 오답노트 개발방

## 1. 실제 버그 발견과 재현

- 기존 오답 목록에는 과목 선택 `#wrong007-filter-subject`(5과목), 수학 전용 `#filter-concept`, 정리 상태 `#v11-filter-status`(전체/사진만/문제 내용 있음)가 동시에 제공됐다.
- 기본 `renderRecords()`는 과목 조건을 반영하지만, 기존 사진정리 v1.1 확장 함수(`v11RenderRecordsBase` 위의 별도 `renderRecords` 래퍼)가 **정리 상태 선택 시 목록을 다시 그리며 과목 조건을 누락**했다. 그 결과 국어 등 비수학 선택 중 수학 오답이 목록에 표시될 수 있었다.
- 또한 과목 변경 `onchange`가 오래된 기본 렌더 함수에 바인딩돼 이후 사진상태·빈 목록 래퍼와 분리됐으며, 수학 개념 선택값을 둔 채 국어로 전환하면 **해당 과목의 모든 기록이 0건으로 숨겨짐**. 비수학 화면에서도 수학 개념 선택/개념별 건수 UI가 표시됐다.
- **실제 Chromium 사전 재현**: [의도한 실패 Actions #42712647937](https://github.com/jinbh99-arch/uri-wrong-answer-qa/actions/runs/42712647937), 변경 전 앱 + 새 회귀 테스트. 가상 5과목 6건/사진2장 등록은 PASS 1건 후, **수학 + ‘문제 내용 있음’이 수학1건 대신 다른 4과목까지 5건을 표시**하여 `WRONG009_NONMATH_FILTER_RESULT: FAIL` (expected 1/actual 5). 기존 WRONG008 10/10 성공을 함께 확인. 이는 브라우저 실제 재현 기록이며 제품 검증 성공으로 보고하지 않음.

## 3. 코드의 최소 변경 (앱 데이터/교육 내용 변경 없음)

- 기존 `index.html`의 `renderRecords()`: 국어·영어·과학·사회 과목이 선택된 동안 **수학 전용 ‘개념별 보기’와 ‘개념별 오답 건수’ 박스를 숨기고**, 기존 수학 개념 선택값만 초기화. *오답 데이터의 conceptId 자체를 변경하지 않는다.* ‘비수학 수학 전용 개념 집계 미지원’ 안내를 표시.
- 기존 v1.1 정리 상태 `renderRecords` 래퍼: 목록을 다시 선별할 때도 **과목 조건을 항상 적용**. ‘문제 내용 있음’ 및 ‘사진만 저장’ 2가지 상태를 포함.
- 마지막 WRONG-003 빈 목록 렌더 래퍼 이후에 `#wrong007-filter-subject` 변경 이벤트를 재연결해 오래된 함수를 다시 호출하지 않도록 함.
- 수학 또는 모든 과목으로 돌아오면 원래 수학 개념 필터/개념별 집계가 다시 나타남. 다른 과목 기록/학년/수학 개념/사진/복수 원인/일반 재풀이/부모 실제 관찰/수동 날짜 메모·JSON 백업 구조는 변경하지 않음.
