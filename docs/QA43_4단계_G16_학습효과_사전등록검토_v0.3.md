# G16 학습효과 실증 사전등록·외부 검토본 v0.3

QA39 v0.2 설계를 확장한 검토용 문서이다. 해당 문서 자체가 연구윤리 승인 또는 사전등록이 아니다.

## 1. 연구 질문
가정용 오답 기록·재풀이·보호자 관찰을 포함한 앱을 사용한 학습자는 학습시간 및 기초수준이 유사한 비교조건에 비해, **독립적으로 채점된 초등 수학 과제**의 사전·사후 점수 변화에서 차이를 보이는가? AI 내부 정답률이나 모의 학생의 점수는 일차 효과지표가 아니다.

## 2. 대상·도구·배정 계획 (모두 사전 검토)
- 연구 참여 학교/가정·학년·학년군, 포함/제외 기준, 학습장애/다문화 참여자 보호를 포함한 접근성, 모집 경로는 **미확정**.
- 2022 개정 수학 **공식 성취기준 코드/원문/학년군**과 독립 평가문항 연결은 교육과정 전문가의 원문 대조·문항 개발과 타당화 후 확정. 아직 원문 검증하지 않은 항목을 공식 검증으로 표시하지 않음.
- 개입 사용시간·과제 노출, 가정환경 차이, 부모 참여도, 기존 사교육, 최초 수준을 기록·통제하는 설계. 개인/반 단위 무작위 배정 가능성과 집단 간 전파 가능성, 비무작위의 한계는 연구자가 결정.
- 중재 기간과 지연평가, 평가지 전후 난도·점수 동등성, 블라인드 채점/채점자 일치도, 접근성·탈락 감소 설계를 사전 확정.

## 3. 결과·표본수·분석 사전명세 초안
- **일차 결과 후보:** 독립 평가과제(0~100점)의 사전·사후 변화에 대한 집단 간 차이. 단, 척도 타당도 미검증.
- 이차 결과 후보: 오답 반복 패턴, 실사용 복습 완주/지연 복습, 보호자 관찰 및 만족도. 다중 비교 제어 방법 사전 확정.
- 표본수·검정력: 실제 분산/군집내상관·기대 최소 유의 차이·기대 탈락률에 기반하여 **연구자·통계전문가가 사전에 계산**, 현재 숫자 확정 불가.
- 분석: 원칙적으로 사전등록된 표본과 결측/탈락 분모, 군집 배정일 경우 군집효과 반영, 사전 점수 공변량, 효과 크기·신뢰구간, 다중검정 처리, 주/민감도 분석 계획을 고정. 비무작위면 인과효과로 주장 금지.
- 결측: 점수 미관측을 **0점으로 대체하지 않는다**. 탈락·동의철회 빈도와 사유, 결측 민감도 구간, 불확실성과 부정·무효 결과 모두 보고. 중간검토/조기 종료 기준도 사전 지정.
- 자료 보안: 가명 ID 연결키와 아동 원자료/사진은 분리해 접근통제된 연구환경에서 처리. 공개 QA GitHub에는 실제 학생 자료 업로드 금지. 최소수집·보존·파기·권리행사는 별도 검토.

## 4. 시행 전 외부 승인·등록 필수
1. 독립 연구자·교육과정 전문가의 평가도구 및 성취기준 대조.
2. 법정대리인 동의와 발달 단계에 맞는 아동 설명·참여 거부/철회권, 학교·기관의 해당 연구윤리 절차 검토.
3. 시범연구 포함 실사용자 자료 처리 및 개인정보·보안 승인.
4. 대조군, 배정, 기간, 모집/표본수/검정력, 사전 분석계획을 **실제 등록**하고 변경 이력/일시 남김.
5. 승인 후 실제 참가자·가명 데이터 수집·외부 독립 분석을 수행하고 유의하지 않은 결과도 공개.

**현재 결과:** 실제 아동 0명·동의 확인 0건·효과 검증 없음. 통계 시뮬레이션 수치는 학습효과 근거가 아니며, G16 미완료이다.
