## 출시 전 의존 관계

1. **사용자 운영 결정 필요:** 클라우드·인증 공급자·도메인·비용 예산·보관 국가·운영자·문의처 선정.
2. **법률·보안 검토 필요:** 법정대리인 권한·동의 근거, 사진/답안 처리항목·위탁·국외 이전, 보존/삭제 정책, 운영 침해 대응 및 백업·키 관리 승인.
3. **공급자 통합 검증 필요:** 실제 API HTTPS, JWT 발급·갱신·회수, 가족 행 격리·사진 객체저장 접근, DB·사진 일관된 백업/PITR, 관리자 접근 통제와 감사.
4. **실기기 수락 필요:** Android/iOS 촬영·OCR 실패/수동 입력, 사진·기록 원본, 복원 승인, 2기기 동시 충돌, 로그인 만료·권한 철회, 오프라인/셀룰러·접근성.
5. **별개 연구 승인이 필요한 G16:** 독립 평가도구, 보호자 동의 및 해당 연구윤리 절차, 외부 사전등록·실제 학생 자료·독립 통계 분석.

## 기계 판독 승인 차단 게이트
`data/qa38-release-readiness-v0.1.json`의 G15 5개와 G16 5개 **모두 BLOCKED**를 유지한다. `tests/qa-release-gates.mjs`은 외부 증빙 없는 자기인증을 검증 실패로 처리한다.

### 불가
- 공개 GitHub Pages에 보호자 JWT·DB 접속정보·실제 자녀 오답/사진 업로드.
- 실제 동의·법률 검토 전에 아동 정보를 수집하거나, 학습효과가 입증됐다고 홍보.
- PR CI 통과만으로 운영 배포, 개인정보 처리 및 G15/G16 완료 처리.

### 단계적 인수 권한
- **개발 기술 QA:** GitHub PR 검사·소스 백업·격리 Pages 점검을 근거로 처리.

- **교육 효과 G16:** 독립 연구자·교육과정 전문가·해당 윤리 승인 및 실제 결과.
